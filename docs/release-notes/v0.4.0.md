## SnapForge 0.4.0 — оверлей съёмки с панелью инструментов, настраиваемые клавиши

- **Оверлей съёмки.** Панель сверху, как в ShareX. Режимы: область, окно, монитор под курсором и «текст из области (OCR) сразу в буфер». Инструменты: рамка, эллипс, линия, стрелка, карандаш, маркер, текст, метка с номером, размытие, пикселизация. Цвета, толщина, отмена и кнопка «скрыть чувствительное после снимка».
- **Рисунок из оверлея попадает в редактор** отдельными редактируемыми объектами, а не вшитыми пикселями.
- **Клавиши.** Глобальные хоткеи можно «записать» любой клавишей, включая PrintScreen и Win; после записи они применяются сразу, есть «Вернуть по умолчанию». У каждого инструмента оверлея своя клавиша, повторы и зарезервированные клавиши отклоняются. Блок горячих клавиш и панели съёмки теперь первый в настройках.

**Файлы релиза**

| Файл | Что это |
| --- | --- |
| `SnapForge-Setup.exe` | установщик: ставится в `%LOCALAPPDATA%\Programs\SnapForge`, права администратора не нужны |
| `SnapForge.exe` | переносная версия (тот же файл; именно его скачивает автообновление) |
| `snapforge-cli.exe` | консольная версия: `capture`, `monitors`, `ocr`, `plugin`, `history` |
| `SHA256SUMS.txt` | контрольные суммы |

**Что важно знать**

- Исполняемые файлы не подписаны: SmartScreen может показать предупреждение «неизвестный издатель». Сверяйте файл с `SHA256SUMS.txt`.
- Права администратора не нужны. Windows 11, в Windows 10 нужна версия 1903 и новее.

**Не проверялось на реальной системе**

- Работа оверлея мышью (рисование, переключение режимов и инструментов), запись клавиш PrintScreen/Win на живой раскладке: покрыто модульными тестами логики, clippy и сборкой, но не ручным прогоном.
- Мониторы с разным масштабом, перетаскивание изображения в сторонние программы, загрузка на настоящие серверы.
