## SnapForge 0.3.0 — плагины в песочнице, встроенный редактор плагинов, CLI

Плагины на Rhai с явными разрешениями — без нативных библиотек и произвольного кода.

- **Плагины.** Плагин — папка или архив `.sfplugin` (zip) с `plugin.toml` (имя, версия, автор, описание, список разрешений) и скриптом на Rhai. Хуки: `on_capture`, `on_before_save`, `on_after_save`; плагин может зарегистрировать действие в панели «после снимка» (`register_action`), пункт меню (`register_menu`) и инструмент редактора (`register_tool`). Если хук падает, правки этого плагина отбрасываются, остальные плагины продолжают работать, ошибка видна в консоли и уведомлением.
- **API.** Операции над изображением: пиксели, прямоугольники и линии, текст (`draw_text`, `measure_text`), размытие и пикселизация области, обрезка, масштаб, наложение с прозрачностью, средний цвет, `distance`, OCR (`img.ocr()`); файлы (`load_image`, `save_image`, `read_text`, `write_text`, `list_dir`); сеть (`http_get`, `http_post`, `http_upload`, `json_get`); буфер обмена; уведомления и окно с текстом; `log`/`print` в консоль плагина. Полный справочник и примеры — `docs/PLUGINS.md`; три готовых плагина (Hello, Watermark, Custom Upload) — в папке `plugins/` и в шаблонах.
- **Разрешения.** `fs.read` и `fs.write` — только указанные абсолютные папки (проверка после раскрытия ссылок и junction, регистр не важен, `..` и корень диска отклоняются); `net` — только указанные домены и их поддомены (без `*`, редиректы не выполняются — они могли бы выйти за список); `clipboard`; `ui`. При установке показывается, что именно плагин просит, и можно установить его выключенным. Если разрешения в `plugin.toml` изменились, плагин останавливается до повторного подтверждения. Токены загрузки лежат в Диспетчере учётных данных и в API плагинов их нет.
- **Песочница и лимиты.** Rhai без доступа к файлам, процессам и окружению; `eval` и загрузка модулей отключены. Лимиты на один вызов: 20 млн операций, 10 с, глубина вызовов 48, строка 1 МБ, массив 20 000, карта 2 000, суммарно 512 МБ пикселей, созданных скриптом. Бесконечный цикл, runaway-рекурсия и раздувание памяти прерываются (это покрыто тестами песочницы вместе с проверкой, что без `net` и `fs.write` скрипт технически не может обратиться к сети или записать файл).
- **Встроенный редактор плагинов** (вкладка «Плагины»): список с включением/выключением, редактор кода с подсветкой Rhai и TOML, шаблоны («Hello», «Водяной знак», «Загрузка на свой сервер»), кнопка «Запустить на тестовом снимке» с консолью вывода и ошибок (по умолчанию «без сети и буфера» — запросы не отправляются), результат-миниатюра, экспорт и импорт `.sfplugin`. Архивы распаковываются строго: без абсолютных путей и `..`, только известные типы файлов, не более 64 файлов и 8 МБ.
- **`snapforge-cli`:** `ocr <файл>` (оффлайн-OCR, `--languages`, `--words`), `plugin list`, `plugin run <id|папка> --image файл --hook имя [--out файл] [--dry-run] [--grant]`. Папка без `--grant` запускается без разрешений.
- Автообновление теперь не обрывает скачивание на медленном канале (таймаут 30 минут вместо 2); SHA-256 проверяется как раньше.

**Файлы релиза**

| Файл | Что это |
| --- | --- |
| `SnapForge-Setup.exe` | установщик: ставится в `%LOCALAPPDATA%\Programs\SnapForge`, права администратора не нужны |
| `SnapForge.exe` | переносная версия (тот же файл; именно его скачивает автообновление) |
| `snapforge-cli.exe` | консольная версия: `capture`, `monitors`, `ocr`, `plugin`, `history` |
| `SHA256SUMS.txt` | контрольные суммы |

**Что важно знать**

- Исполняемые файлы не подписаны: SmartScreen может показать предупреждение «неизвестный издатель». Сверяйте файл с `SHA256SUMS.txt`.
- Права администратора не нужны. Windows 11, в Windows 10 нужна версия 1903 и новее.
- Плагин с разрешениями `net` и `fs.read` может отправить доступные ему файлы на разрешённые ему хосты — одобряйте только то, что понимаете.
- Приватность: по умолчанию сеть используется только для проверки обновлений; загрузка снимков, скачивание модели лиц и сетевые запросы плагинов — только после вашего включения. Телеметрии нет.
- Размер файла вырос (около 43 МБ): внутри движок ONNX для поиска лиц и интерпретатор Rhai. Автообновление версии 0.1.0/0.2.0 скачивает файл с таймаутом 2 минуты: на очень медленном канале (меньше ≈ 3 Мбит/с) обновитесь вручную со страницы релизов — после этого обновления проблема исчезнет.

**Ограничения**

- Память плагина ограничена косвенно (размеры строк, массивов, карт и бюджет пикселей), а не точным лимитом кучи; время ограничено для выполнения скрипта, а блокирующий сетевой вызов — таймаутом HTTP в 20 с.
- Сетевые API плагинов проверены на подставном транспорте и на отказах песочницы; реальные запросы к чужим серверам из плагинов не проверялись. Инструмент редактора от плагина заменяет базовую картинку (объекты поверх остаются) и проверен через ядро, но не нажатием мыши в окне.
- Не проверялось на реальной системе: мониторы с разным масштабом (на тестовой машине все 100 %), перетаскивание изображения в сторонние программы, щелчки по окну установщика, «Перезапустить от администратора», загрузка на настоящие серверы Discord/Telegram/S3.
- OCR требует установленного в Windows языка с распознаванием текста; поиск лиц — отдельно скачиваемая модель и может ошибаться (есть проверка перед применением).
