## SnapForge 0.2.0 — панель «после снимка», лица и OCR, графики и загрузка

Автоматические действия после съёмки, оффлайн-обработка снимка и первые (выключенные по умолчанию) назначения для загрузки.

- **Панель «после снимка».** После каждого снимка (можно отключить) появляется панель с галочками, которую можно поменять прямо в этот момент: сохранить, в буфер, открыть в редакторе, загрузить, размыть лица, распознать текст и скопировать его, скрыть чувствительное, обрезать пустые поля, добавить водяной знак (текст или PNG), уменьшить размер. Наборы действий («Редактор», «Сохранить и в буфер», «Приватный» и свои) сохраняются в настройках. Порядок фиксирован: сначала правки картинки (лица → чувствительный текст → обрезка → водяной знак → уменьшение), затем выводы (сохранение, буфер, загрузка, текст, редактор); сбой одного шага не останавливает остальные. В историю попадает уже обработанный снимок — не исходный.
- **Проверка перед применением.** Если выбраны «размыть лица» или «скрыть чувствительное», сначала идёт анализ, и найденные области показываются рамками на снимке со списком: любую можно снять галочкой. Закрываются области сочетанием размытия и пикселизации (текст — пикселизацией или размытием на выбор); проверено, что OCR после этого не читает скрытый адрес.
- **OCR оффлайн.** `Windows.Media.Ocr` на языках, установленных в Windows, без облака. Маленький интерфейсный текст читается заметно лучше, если картинку увеличить, поэтому снимок распознаётся в исходном размере и в 2× (выигрывает проход, где распознано больше символов). Кнопка «Распознать текст (OCR)» в редакторе показывает текст и копирует его.
- **Чувствительный текст.** Адреса почты, телефоны (10–15 цифр), типичные ключи и токены (AWS, GitHub, OpenAI-подобные, Slack, JWT, токен Telegram-бота, приватные ключи, `password=…`) и длинные случайные строки. Это эвристика на регулярных выражениях: она может пропустить нестандартный формат или принять за секрет обычную строку — поэтому есть проверка.
- **Лица оффлайн.** Небольшая ONNX-модель (Ultra-Light-Fast-Generic-Face-Detector, лицензия MIT) выполняется на этом компьютере чистым Rust (`tract`, без нативных библиотек). Модель **не вшита**: скачивается по кнопке в панели или в настройках (≈1,2 МБ), SHA-256 сверяется с зашитым в программу значением, файл с неверным хешем отбрасывается. Без модели функция пишет «модель не установлена» и ничего не делает. Большие снимки разбиваются на перекрывающиеся окна, чтобы мелкие лица не терялись.
- **Графики.** Инструмент «График» в редакторе: столбчатая, линейная и круговая диаграммы из таблицы в окне или вставленной из буфера (CSV/TSV с запятой, точкой с запятой или табуляцией; десятичная запятая или точка). Подписи, цвета рядов, легенда, значения. График — обычный объект: двигается, меняет размер, его данные открываются снова («Данные графика…»).
- **Загрузка (выключена по умолчанию).** Нужно включить общий переключатель (с подтверждением), включить конкретное назначение и выбрать его по умолчанию; пока этого нет, сеть не используется. Назначения: свой HTTP-аплоадер (URL, метод POST/PUT, заголовки, поле файла или «сырое» тело, дополнительные поля, путь к ссылке в JSON-ответе), webhook Discord, бот Telegram, S3-совместимое хранилище (подпись AWS Signature V4, проверена по примерам из документации AWS; адресация path-style и virtual-hosted, публичный адрес для ссылки). Ссылка копируется в буфер.
- **Токены и ключи** лежат только в Диспетчере учётных данных Windows (DPAPI). В настройках и на диске их нет; значения, прочитанные или записанные программой, вырезаются из журнала и отчётов о сбоях. В заголовках и URL своего аплоадера секрет подставляется через `{secret:имя}`.
- Установка, автообновление (с SHA-256), диагностика и всё из 0.1.0 сохранены.

**Файлы релиза**

| Файл | Что это |
| --- | --- |
| `SnapForge-Setup.exe` | установщик: ставится в `%LOCALAPPDATA%\Programs\SnapForge`, права администратора не нужны |
| `SnapForge.exe` | переносная версия (тот же файл; именно его скачивает автообновление) |
| `snapforge-cli.exe` | консольная версия: `capture`, `monitors`, `history` |
| `SHA256SUMS.txt` | контрольные суммы |

**Что важно знать**

- Исполняемые файлы не подписаны: SmartScreen может показать предупреждение «неизвестный издатель». Сверяйте файл с `SHA256SUMS.txt`.
- Права администратора не нужны (кнопка «Перезапустить от администратора» нужна только для горячих клавиш поверх окон, запущенных от администратора).
- Приватность: по умолчанию сеть используется только для проверки обновлений. Загрузка снимков и скачивание модели лиц — только после вашего явного включения/нажатия. Телеметрии нет.
- Для OCR в Windows должен быть установлен хотя бы один язык с распознаванием текста.

**Ограничения**

- Загрузка проверена юнит-тестами с подставным транспортом (формирование запросов, подпись AWS по документации, разбор ответов, отказ при выключенных переключателях) и реальной записью/чтением Диспетчера учётных данных, но **не проверялась на настоящих серверах** Discord, Telegram, S3 и сторонних HTTP-сервисов. У Telegram ссылка на сообщение есть только для чатов с публичным именем.
- Поиск лиц проверен на фотографии толпы, а не на скриншотах: маленькая модель может пропустить лицо или принять за лицо что-то другое, поэтому есть проверка перед применением. Картинки с лицами в README нет (только выдуманные данные).
- Если выбраны «копировать в буфер» и «распознать текст», в буфере остаётся текст.
- Всё из ограничений 0.1.0 по-прежнему в силе: не проверялись мониторы с разным масштабом (на тестовой машине все 100 %), перетаскивание в сторонние программы и щелчки по окну установщика.
- Плагинов нет — они запланированы на 0.3.0.
